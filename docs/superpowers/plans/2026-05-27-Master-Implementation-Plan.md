# MenuLens Pro 核心功能開發主計畫 (Master Plan)

> **開發原則：** 採用「功能完工才推進」策略。每個階段必須完成【界面開發 -> 邏輯實作 -> 整合測試】並獲得驗證後，方可開啟下一階段。

## 功能開發順序

1.  **階段一：AI 智能辨識與翻譯模組 (Core AI Module)**
    *   目標：實現拍照/上傳菜單後，自動辨識、翻譯並生成記帳明細。
2.  **階段二：財務數據可視化與趨勢模組 (Data Insights Module)**
    *   目標：建立預算追蹤、支出類別圓餅圖與趨勢折線圖。
3.  **階段三：生活工具箱 (Toolbox Module)**
    *   目標：整合匯率換算、單位轉換等輔助工具。

## 階段一：AI 智能辨識與翻譯模組 (細部執行清單)

### 任務 1.1: 建立 AI 對話與結果展示組件
*   **目標：** 建立類似 Chat UI 的互動介面與辨識結果卡片。
*   - [ ] 1. 在 `index.html` 中新增 AI 互動視窗容器 `#ai-container`。
*   - [ ] 2. 在 `logic.js` 中新增 `renderAIMessage(content)` 函數處理對話氣泡。
*   - [ ] 3. 實作 `renderRecognitionResult(data)` 函數，以卡片形式展示辨識出的品項、原價、翻譯後名稱。
*   - [ ] 4. 加入「確認並記帳」按鈕，點擊後觸發既有的記帳邏輯。

### 任務 1.2: 整合影像上傳與模擬 AI 處理
*   **目標：** 處理圖片輸入並模擬後端 AI 處理流程。
*   - [ ] 1. 實作圖片預覽功能，讓使用者確認上傳的圖片。
*   - [ ] 2. 實作 `processImageWithAI(imageFile)`：模擬延遲 2 秒（Loading 狀態），並返回模擬的 OCR/翻譯資料。
*   - [ ] 3. 整合 Loading 動畫，提升使用者體驗。

### 任務 1.3: 整合至既有記帳系統
*   **目標：** 確保 AI 辨識的結果能無縫存入現有的 `localStorage` 或資料結構。
*   - [ ] 1. 修改 `saveExpense()` 邏輯，支援從 AI 卡片直接導入資料。
*   - [ ] 2. 驗證：AI 辨識出的價格是否正確填入，類別是否自動匹配。
