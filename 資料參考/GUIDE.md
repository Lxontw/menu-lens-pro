# 🔑 如何取得您的 Gemini API Key (新手指南)

為了讓 MenuLens Pro 能為您翻譯菜單，您需要一個 **Gemini API Key**。這就像是一把「數位鑰匙」，讓 App 能與 Google 的 AI 大腦溝通。

**不用擔心，這個過程是免費的，且只需設定一次！**

---

## 🛠️ 申請步驟 (只需 1 分鐘)

### 第一步：進入申請頁面
請點擊下方連結，使用您的 **Google 帳號** 登入：
👉 [**Google AI Studio - 取得 API Key**](https://aistudio.google.com/app/apikey)

### 第二步：建立金鑰
進入頁面後，請按照以下操作：
1. 看到畫面左側或中間的 **「Create API key」** 按鈕 $\rightarrow$ **點擊它**。
2. 選擇 **「Create API key in new project」** (在新專案中建立 API 金鑰)。
3. 系統會花幾秒鐘時間生成，隨後會彈出一個視窗顯示一串長長的英數字組合 (例如：`AIzaSy...`)。

### 第三步：複製金鑰
- 點擊該金鑰旁的 **「Copy」** 按鈕，將這串金鑰複製到您的剪貼簿中。

---

## ⚙️ 如何在 MenuLens Pro 中設定？

1. 開啟 **MenuLens Pro** 應用程式。
2. 點擊右上角的 **設定圖示 (⚙️)**。
3. 在 **「Gemini API 金鑰」** 欄位中，將剛才複製的金鑰 **貼上**。
4. 選擇您想要的模型 (建議使用 `Gemini 2.0 Flash` 以獲得最快速度)。
5. 點擊最下方的 **「儲存並返回」**。

**🎉 設定完成！您現在可以開始掃描美食了！**

## ❓ 常見問題 (FAQ)

**Q: 這需要付費嗎？**
A: Google AI Studio 為個人開發者提供免費額度，對於一般的旅遊翻譯用途，完全足夠使用，不需要付費。

**Q: 我的金鑰安全嗎？**
A: 是的。MenuLens Pro 採用純前端設計，您的金鑰**僅儲存在您自己手機的瀏覽器中**，不會被上傳到任何伺服器，開發者也無法看到您的金鑰。

**Q: 如果金鑰失效了怎麼辦？**
A: 您可以隨時回到 [AI Studio](https://aistudio.google.com/app/apikey) 刪除舊金鑰並重新生成一組新的，然後在 App 的設定頁面更新即可。
